## 2024-05-24 - [Optimization] FastAPI / Strawberry CPU & Event Loop bottlenecks
**Learning:** In Strawberry GraphQL / FastAPI applications, computing constant sets (like `dataclasses.fields()`) inside resolver functions creates a hidden CPU bottleneck on every request. Furthermore, using synchronous network clients (like the default meilisearch client) directly inside standard `def` resolvers blocks the ASGI event loop, devastating concurrent performance under load.
**Action:** Always pre-compute static dataclass fields at the module level. Wrap synchronous network calls inside `asyncio.to_thread()` within `async def` Strawberry resolvers. Strawberry correctly discovers and awaits `async def` resolvers automatically, requiring no call site changes to `strawberry.field()`.
