## 2023-10-27 - Preventing event loop starvation in Strawberry Fastapi
**Learning:** By default, Strawberry resolvers running inside FastAPI act exactly like standard FastAPI endpoint handlers - if they are standard `def` functions, they are executed on the main event loop asynchronously, which is a big performance hit for blocking I/O calls like the standard `meilisearch` client (which uses `requests`). This effectively starves the event loop under load.
**Action:** When working with synchronous libraries (like the standard `meilisearch` python client) inside a Strawberry/FastAPI application, wrap the blocking call in `asyncio.to_thread` and make the resolver an `async def`. This ensures the synchronous I/O blocks a background thread instead of the primary event loop, significantly boosting concurrency.
